# AGENTS.md

Restaurant menu site on Orchard Core 3.0.1 (.NET 10), Razor theme, for the Óbuda University K-MOOC Orchard Core course.

- `docs/design.md`: architecture, content model, features
- `docs/plan.md`: implementation slices and their order
- `raw/`: course material, requirements, instructor feedback (local only, not in git)
- `src/RestaurantMenu.Web`: host app
- `src/Modules/RestaurantMenu.Module`: all custom functionality
- `src/Themes/RestaurantMenu.Theme`: all visuals
- `justfile`: commands; run `just check` before committing
